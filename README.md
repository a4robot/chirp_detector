# Chirp Detector: Scan Distortion & Reconstruction

A professional DSP tool to detect and reconstruct mechanical distortions in line scan camera data.

## Project Structure
- `src/`: Modular logic for image creation, mechanical chaos simulation, and DSP reconstruction.
- `data/`: Artifacts generated by the pipeline.
- `main.py`: Unified pipeline runner.

## Quick Start
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the full pipeline (Generate → Distort → Reconstruct):
   ```bash
   python main.py
   ```
3. Check the results in `data/` and `data/analysis_report.txt`.

## Algorithm Overview
- **Vibration correction**: Per-row sub-pixel centroid detection on a vertical tracker band.
- **Motion correction**: Hilbert Transform phase-inversion on a vertical chirp column, with PCHIP-smoothed monotonicity for robust Y-axis reconstruction.
- **Reconstruction**: Sub-pixel horizontal shift correction + keep/drop recipe + 1D interpolation for a perfect reference restaurarion.
